# ระบบรับสมัครนักเรียน นักศึกษาออนไลน์ (Online Admission Management System)
### วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ ประจำปีการศึกษา 2570

ระบบรับสมัครนักเรียน นักศึกษาออนไลน์แบบครบวงจร (Full-stack Web Application) พัฒนาขึ้นโดยอ้างอิงโครงสร้างแบบฟอร์ม **"ใบสมัครเข้ารับคัดเลือกเพื่อศึกษาต่อเป็นกรณีพิเศษ (โควตา) วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ ประจำปีการศึกษา 2570"** ครบถ้วนทุกหัวข้อ ทุกช่องกรอก ไม่มีการตัดทอน พร้อมระบบตรวจสอบเอกสาร การคัดเลือก การมอบตัวนักศึกษาใหม่ และการส่งออกข้อมูลสู่งานทะเบียน (ศธ.02)

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 1. ระบบสำหรับผู้สมัครเรียน (Front-end Portal)
- **หน้าแรก (Landing Page):** แสดงอัตลักษณ์วิทยาลัย ข้อมูลหลักสูตร ปวช./ปวส. สาขาวิชาที่เปิดรับ กำหนดการ และปุ่มบริการด่วน
- **แบบฟอร์มใบสมัครออนไลน์ดิจิทัล (Multi-step Application Form):**
  - **ส่วนหัว:** ระบุชื่อเอกสารและวิทยาลัยชัดเจน พร้อมช่องอัปโหลดรูปถ่ายหน้าตรงขนาด 1 นิ้ว (แสดงตัวอย่างรูปภาพก่อนบันทึก)
  - **ระดับการศึกษาที่สมัคร:** เลือกระดับ ปวส. (สายตรง), ปวส. (ม.6/ปวช. ต่างสาขา) หรือ ปวช.
  - **ข้อ 1 ข้อมูลส่วนตัว:** ชื่อ-นามสกุล, วันเกิด, เดือนเกิด, พ.ศ. เกิด (แยกช่องตามต้นฉบับ), เลขบัตรประชาชน 13 หลัก พร้อมระบบตรวจสอบ Checksum อัตโนมัติ และป้องกันการสมัครซ้ำในปีการศึกษาเดียวกัน
  - **ข้อ 2 ข้อมูลบิดา:** ชื่อ-สกุลบิดา, อายุ (ปี), อาชีพ
  - **ข้อ 3 ข้อมูลมารดา:** ชื่อ-สกุลมารดา, อายุ (ปี), อาชีพ
  - **ข้อ 4 ที่อยู่ปัจจุบัน:** บ้านเลขที่, หมู่, ซอย, ถนน, ตำบล, อำเภอ, จังหวัด (77 จังหวัด), รหัสไปรษณีย์, เบอร์โทรศัพท์ 10 หลัก
  - **ข้อ 5 ข้อมูลการศึกษาปัจจุบัน:** ระดับชั้น (ม.3, ปวช.3, ม.6), ชื่อสถานศึกษา, เลขที่, ตำบล, อำเภอ, จังหวัด, GPAX 5 ภาคเรียน, สาขาวิชาเดิม
  - **ข้อ 6 ความประสงค์เลือกสาขาวิชา:**
    - ระดับ ปวส.: เลือก 1 สาขาวิชา
    - ระดับ ปวช.: เลือกสาขาวิชาลำดับที่ 1 และลำดับที่ 2 (สำรอง) จากฐานข้อมูลจริงของวิทยาลัย
  - **ส่วนหลักฐานประกอบการสมัคร:** แนบเอกสารผลการเรียน 5 เทอม, สำเนาบัตรประชาชน/ทะเบียนบ้าน, เกียรติบัตร (รองรับ PDF, JPG, PNG)
  - **ส่วนลงชื่อผู้สมัคร:** ช่องพิมพ์ชื่อรับรอง + ผ้าใบลงลายเซ็นอิเล็กทรอนิกส์ (Digital Signature Canvas Pad) + วันที่ เดือน พ.ศ. + ความยินยอม PDPA
- **หน้าตรวจสอบสถานะ (Status Tracking):**
  - ตรวจสอบด้วยเลขประจำตัวประชาชน หรือ รหัสติดตาม (Tracking Code) พร้อมยืนยันด้วยเบอร์โทรศัพท์ 4 ตัวท้าย
  - แสดงสถานะตาม 10 ขั้นตอนราชการแบบ Real-time
  - **ระบบแก้ไขเอกสาร (In-place Re-upload):** หากเอกสารถูกระบุว่าไม่ผ่าน/ต้องส่งใหม่ ผู้สมัครสามารถดูเหตุผลและอัปโหลดไฟล์ใหม่ได้ทันที
- **การพิมพ์และสร้างเอกสาร PDF ทางการ (A4 Print Engine):**
  - **ใบสมัครเข้ารับคัดเลือก (PDF):** รูปแบบตรงตามเอกสารต้นฉบับราชการ มีช่องรูปถ่าย ตารางหัวข้อ 1-6 และส่วนลงชื่อ
  - **ใบมอบตัวนักศึกษาใหม่ (PDF):** สร้างจากข้อมูลเดิมอัตโนมัติ พร้อมรหัสนักศึกษาใหม่และข้อมูลผู้ปกครอง/พยาน

### 2. ระบบสำหรับเจ้าหน้าที่ (Back-end / Admin Dashboard)
- **ระบบยืนยันตัวตน (Authentication & RBAC):**
  - ระบบความปลอดภัย JWT & Secure Cookies
  - บทบาท 3 ระดับ: **Super Admin**, **Admission Admin**, **Document Staff**
- **Dashboard ภาพรวมสถิติ:**
  - สถิติผู้สมัครรวม, ปวช., ปวส., รอตรวจเอกสาร, เอกสารไม่ครบ, ผ่านคัดเลือก, มอบตัวแล้ว
  - กราฟสรุปจำนวนผู้สมัครเทียบเป้าหมายโควตาแต่ละสาขาวิชา, กราฟแยกตามระดับการศึกษา, จังหวัด และโรงเรียนเดิม
  - เลือกดูข้อมูลแยกตามปีการศึกษาได้
- **ระบบจัดการข้อมูลผู้สมัคร (Applicant Management):**
  - ตารางผู้สมัคร ค้นหา กรองตามระดับ/สาขา/สถานะ เรียงลำดับ และแบ่งหน้า Pagination
  - ระบบปกปิดเลขบัตรประชาชน (Masking e.g. `1-1002-xxxxx-34-1`)
  - หน้าต่าง Dossier ตรวจสอบข้อมูลผู้สมัครรายบุคคล
- **ระบบตรวจเอกสาร (Document Review Module):**
  - ตรวจเอกสารแนบรายชิ้น (ผ่าน, ไม่ผ่าน, ต้องส่งใหม่) พร้อมระบุเหตุผลเพื่อแจ้งเตือนไปยังผู้สมัคร
- **ระบบการคัดเลือกและโควตา (Admission Selection):**
  - จัดการผลการคัดเลือก (ผ่าน, สำรอง, ไม่ผ่าน) แบบกลุ่ม (Batch Selection)
  - จัดลำดับผู้สมัครสำรอง และประกาศผลการคัดเลือกเข้าสู่ระบบ
- **ระบบมอบตัวนักศึกษาใหม่ (Enrollment):**
  - บันทึกรหัสนักศึกษาใหม่ ข้อมูลผู้ปกครอง พยานการมอบตัว
  - สั่งพิมพ์ใบมอบตัว PDF ได้ทันที
- **ระบบจัดการข้อมูลหลัก (Master Data):**
  - จัดการปีการศึกษา (เปิด/ปิดรับสมัคร)
  - จัดการสาขาวิชา เพิ่ม/แก้ไข/เปิด-ปิดรับสมัคร และเป้าหมายโควตา
- **ระบบส่งออกข้อมูล (Export Module):**
  - ส่งออกไฟล์ **Excel (.xlsx)** และ **CSV (UTF-8 with BOM)**
  - คอลัมน์จัดเรียงตามมาตรฐานงานทะเบียนวิทยาลัย (ศธ.02)
- **ระบบแจ้งเตือนอัตโนมัติ (Notifications):**
  - โครงสร้างรองรับ LINE Messaging API / LINE Notify และ Email SMTP
  - บันทึกประวัติการแจ้งเตือนครบทั้ง 7 เหตุการณ์สำคัญ

## 🛠 เทคโนโลยีที่ใช้พัฒนา (Technology Stack)

- **Frontend:** Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Lucide Icons
- **Backend:** Next.js Route Handlers (Serverless/Node.js API)
- **Database & ORM:** Prisma ORM 5.22.0 เชื่อมต่อ SQLite Database (`dev.db` พร้อมใช้งานแบบ Zero-config หรือสลับเป็น PostgreSQL ได้)
- **Security:** bcryptjs (เข้ารหัสรหัสผ่าน), jsonwebtoken (JWT Auth), HTTP-only Cookies
- **Exporting:** xlsx (ExcelJS / SheetJS) รองรับภาษาไทยเต็มรูปแบบ
- **Printing:** CSS `@media print` มาตรฐาน A4 Portrait สำหรับเอกสารราชการ

## 🚀 วิธีการติดตั้งและรันระบบ (Setup & Running Guide)

### 1. การติดตั้ง Dependencies
```bash
npm install
```

### 2. การตั้งค่า Environment Variables
คัดลอกไฟล์ `.env.example` เป็น `.env`:
```bash
cp .env.example .env
```
ตรวจสอบและตั้งค่าใน `.env`:
```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="websamak2_jwt_secret_thaluang_admission_2570_secure_key"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
NEXT_PUBLIC_COLLEGE_NAME="วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์"
NEXT_PUBLIC_ACADEMIC_YEAR="2570"

# การตั้งค่าแจ้งเตือน (ระบุเมื่อต้องการใช้งานจริง หากเว้นว่างระบบจะบันทึกใน Log)
LINE_NOTIFY_TOKEN=""
LINE_CHANNEL_ACCESS_TOKEN=""
SMTP_HOST=""
SMTP_PORT=""
SMTP_USER=""
SMTP_PASS=""
SMTP_FROM=""
```

### 3. การเตรียมฐานข้อมูลและ Seed ข้อมูลเริ่มต้น
```bash
# ซิงค์ Schema ไปยังฐานข้อมูล
npm run db:push

# ใส่ข้อมูลเริ่มต้น (ปีการศึกษา 2570, สาขาวิชาจริงของวิทยาลัย, บัญชีเจ้าหน้าที่, ตัวอย่างผู้สมัคร)
npm run db:seed
```

### 4. รันโปรเจกต์
- **สำหรับ Development:**
```bash
npm run dev
```
- **สำหรับ Production:**
```bash
npm run build
npm run start
```
เปิดบราวเซอร์ไปที่: `http://localhost:3000`

## 🔑 บัญชีผู้ใช้งานระบบเจ้าหน้าที่เริ่มต้น (Default Accounts)

| บทบาท (Role) | ชื่อผู้ใช้ (Username) | รหัสผ่าน (Password) | สิทธิ์การใช้งาน |
| :--- | :--- | :--- | :--- |
| **Super Admin** | `admin` | `admin123456` | จัดการทุกฟังก์ชันในระบบ, ผู้ใช้งาน, ข้อมูลหลัก, ส่งออกข้อมูล |
| **Admission Admin** | `admission` | `staff123456` | จัดการใบสมัคร ตรวจเอกสาร คัดเลือก มอบตัว และส่งออกข้อมูล |
